# Verkstedhåndboka

Nettbasert verkstedhåndbok for verksted og undervisning (VG2 Industriteknologi).

**Kapitler:** toleranser (ISO 286), passninger, generelle toleranser (ISO 2768), form- og beliggenhetstoleranser (ISO 1101), metriske gjenger og rørgjenger, overflateruhet, skjæredata, materialer og vekt, tommegjenger (UNC/UNF) sveisesymboler (ISO 2553), pneumatikk, hydraulikk, elektro, fysikk og matematikk.

Hele appen er én statisk fil, `index.html`. Ingen byggesteg eller avhengigheter.

## Kjøre lokalt
Åpne `index.html` i nettleseren.

## Deploy
Vercel: importer repoet, velg Framework Preset **Other**, la Build Command og Output Directory stå tomme.
